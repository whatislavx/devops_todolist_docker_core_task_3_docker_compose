# Django-Todolist

Django-Todolist — це веб-додаток для списку справ з найосновнішими функціями більшості веб-додатків, тобто облікові записи/вхід, API та (частково) інтерактивний користувацький інтерфейс.

---
CSS | [Skeleton](http://getskeleton.com/)
JS  | [jQuery](https://jquery.com/)

## Як запустити
Спробуйте, встановивши залежності. (Працює тільки з python >= 3.8 через Django 4)

    pip install -r requirements.txt

Створіть схему бази даних:

    python manage.py migrate

А потім запустіть сервер (за замовчуванням: http://localhost:8000)

    python manage.py runserver


Тепер ви можете переглянути [API](http://localhost:8000/api/)
або почати з [головної сторінки](http://localhost:8000/)

## Завдання
#### Попередні умови
- Зробіть форк цього репозиторію

#### Вимоги

1. Підготуйте файл `docker-compose.yml`, який буде збирати та запускати як базу даних MySQL, так і додаток Todolist.
2. Видаліть `RUN python manage.py migrate`, оскільки база даних більше не доступна під час збірки.
3. Переробіть `ENTRYPOINT` для виконання як міграції бази даних, так і запуску програми. Приклад:
`ENTRYPOINT ["sh", "-c", "command1 && command2"]`
4. Додаток повинен працювати без проблем після запуску `docker-compose up`.
5. Створіть файл `INSTRUCTION.md` з детальними інструкціями щодо запуску та зупинки контейнерів за допомогою docker-compose.
6. Завдання (Todos) повинні зберігатися в базі даних MySQL з підключеним постійним томом (persistent volume).
7. Створіть PR з вашими змінами та прикріпіть його для перевірки на платформі.
